# VocabFlow · 生词本

一个「以添加生词为核心」的英语学习 App。纯前端实现，无需安装任何东西，双击就能用。

## 打开方式

- **方式一（最简单）**：双击 `打开 VocabFlow.cmd`，或直接双击 `index.html`。
- **方式二**：把整个 `E:\dsh gz` 文件夹拷到任意位置，仍然可用，数据跟着浏览器走。
- 数据保存在浏览器的 localStorage 里（同一台电脑、同一个浏览器、同一个文件路径才算同一份数据），**建议每周用「词库 → 导出」备份一次**。

## 功能一览

| 模块 | 说明 |
| --- | --- |
| 词书（考纲词表） | 内置 **CET-4 考纲 3820 词**、**CET-6 考纲 2025 词**（音标、词性、释义、**英文例句**、**词频分层**）：按字母/关键词/词频筛选，**点一下就把词加进生词本**，可「加入当前 N 个」批量加；显示已加入进度 |
| 学习（逐词过词表） | 选词书 + 字母区间 + 每组词数，一屏一词：「认识」跳过、「不认识」当场收进生词本，可先看释义、可撤销；进度按词书分别保存，与复习完全独立 |
| 学习范围 | 只学某一级别（CET-4 / CET-6 / 考研…）：复习、测验、首页统计、每日任务都只算这个范围，下拉框随时切换 |
| 首页 | 今日待复习数量、连续天数、14 天复习量柱状图、接下来要复习的词 |
| 添加生词 | 单词 / 音标 / 词性 / **级别** / 释义 / 例句 / 标签，右侧实时预览卡片样式；`Ctrl + Enter` 保存；支持语音输入（Chrome / Edge） |
| 批量添加 | 把笔记里的多行词直接贴进来，自动识别 Tab、逗号、竖线、`n.` 词性、`/音标/`，先预览再导入，自动跳过重复 |
| 词库 | 搜索（单词/释义/例句/标签）、按标签与状态筛选、排序、列表/卡片视图、点开看复习数据、编辑、删除、多选批量加标签/导出/删除 |
| 复习 | 卡片式「先回忆 → 揭晓 → 四档自评」，SM-2 间隔重复自动算下次时间；`Space` 揭晓，`1~4` 评分，`Ctrl+Z` 撤销 |
| 测验 | 选择题 + 拼写题交替，答错的词会自动放回复习队列，提供正确率与错题回顾 |
| 导入导出 | JSON（保留复习进度，用于备份/迁移）、CSV（Excel 可直接打开编辑）、CSV 模板下载 |
| 其他 | 深色模式、手机端底部导航、发音朗读（手机/桌面都能响：在线 TTS 优先，系统语音兜底）、设置每日新词/复习上限与测验题量、**例句中文翻译**（手动填或一键在线翻译，自动缓存） |

## 间隔重复规则（SM-2 简化版）

四档评分：**忘记了 / 有点难 / 记得 / 很简单**，会调整记忆强度（ease）与间隔：

- 忘记了：重置进度，10 分钟后再出现，本轮末尾会再考一次；
- 有点难：间隔 ×1.2，不放宽；
- 记得：1 天 → 3 天 → 间隔 × 记忆强度；
- 很简单：2 天 → 5 天 → 间隔 × 记忆强度 × 1.25；
- 间隔 ≥ 21 天记为「已掌握」；
- 1 天以上的复习统一安排在当天早上 8 点，避免半夜弹出任务。

## 批量导入支持的写法

```
resilient	有韧性的              ← Tab（从 Excel 复制）
meticulous, 一丝不苟的           ← 逗号
mitigate | 减轻；缓和            ← 竖线
revenue n. 收入；营业额          ← 自动识别词性
scrutiny, /ˈskruːtəni/ 仔细检查    ← 自动识别音标
```

带表头的 CSV 可以多一列「级别」（或 level / 词书）：

```
单词,音标,词性,级别,释义,例句
abandon,/əˈbændən/,v.,CET-4,放弃,They had to abandon the plan.
```

导入时若没写级别，会自动归入当前学习范围（范围为「全部」时不归级）。

## 学习范围怎么用

1. 首页「学习范围」下拉框里选 **CET-4**（或 CET-6、考研、雅思…）；
2. 首页的今日任务、复习队列、测验出题、掌握数都只统计这个范围；
3. 词库里可以用「全部级别」下拉筛选、也能点词卡上的级别标签直接切过去；
4. 想扩范围就切回「全部词库」；已经复习过的进度不会丢，切回来继续算。

「级别 / 词书」是自由字段：在添加生词时填 `雅思`、`专八`、`我的阅读笔记` 都行，会作为新的选项出现在下拉框里。

## 词书（考纲词表）怎么用

1. 底部导航点 **词书**；
2. 上面选 **CET-4 / CET-6**，用字母行或搜索框找到词（例如搜「放弃」也能搜到 abandon）；
3. **点一下整行 = 加入生词本**（自动带上音标、词性、级别标签），已加入的会变灰显示「✓ 已加入」；
4. 想批量：先筛到想要的子集（比如 A 开头、只看未加入），再点右上「加入当前 N 个」；
5. 顶部能看到「已加入 x / 3820」的进度。

加进去的词和手动添加的完全一样，可以直接进复习队列、测验、导出备份。

词表里 **5060 个词带英文例句**（来自离线例句库，长度最短的一句），加进生词本后，学习卡、复习卡、词卡、测验反馈都会显示例句；剩下 700 个词没有例句，这些位置会**整块隐藏**，不会出现 undefined。

## 学习（逐词过词表）怎么用

1. 底部导航点 **学习**；
2. 选词书（CET-4 / CET-6 / 生词本）、字母区间（如 A–F）、每组词数、顺序（字母 / **按词频** / 随机）；
3. 「开始学习」后一屏一个词：
   - **✓ 认识** → 跳过，以后不再出现；
   - **✗ 不认识** → 显示释义并自动加入生词本（已经在生词本里的只提示，不重复加）；
   - **先看释义** → 看完再决定，适合模棱两可的词；
4. 点错了按 **Z** 或「撤销上一步」回退（如果是「不认识」已加进生词本，需要去词库删）；
5. 一组学完会列出这组「不认识」的词，可直接「继续学 N 个」，或调整范围。

学习进度按词书分开记录，和生词本的 SM-2 复习互不影响；点「重置本词书进度」可只清空这本书的学习记录。**导出 JSON 现在会一并保存学习进度，换设备导入即可恢复。**

## 词频分层是怎么来的

数据源自带一个 0–1 的**书内词频分**（CET-4 大约 0.66–1.0、CET-6 大约 0.30–0.50，两本书不是同一把尺子）。所以按**每本书内的分位数**分层，而不是写死数值：

- 前 30% → **高频**（橙色标）
- 中间 40% → **中频**
- 后 30% → **低频**（灰色标）

词书页可以按这三档筛选，「按词频」排序时高频在前；学习模式的「按词频」就是先过最高频的词。少数精讲词在源数据里没有词频分，不做分层。

## 常见问题

**数据会不会丢？** 不会自己丢，但清浏览器缓存、换浏览器、换电脑会看不到旧数据。用「导出 JSON」备份，在新环境里「导入」即可恢复复习进度。

**想从零开始？** 首页首次打开会自动放 18 个示例单词；词库支持多选批量删除，或者用「设置 → 清空全部数据」。删除示例词不影响你自己的词。

**发音没声音？** 用的是系统语音，Windows 可在「设置 → 时间和语言 → 语音」里安装英语语音包；设置里可以指定具体发音人。

**手机能用吗？** 能。把 `index.html` 等文件放到手机的浏览器里打开，或部署到任意静态托管（GitHub Pages 等）即可；手机端底部是导航栏。复习卡片支持左右滑动（左滑=忘记，右滑=很简单），揭晓答案会自动朗读单词。

**例句翻译怎么用？**
- 学习卡 / 复习卡 / 词库详情 / 测验反馈里的例句下方，点「🌐 翻译例句」即可在线翻译，结果自动缓存；
- 手动在「编辑」弹窗里的「例句翻译」框填写也行；
- 没有例句的词，词库详情里会出现「📖 在线补例句」按钮，自动从免费词典拉一句英文例句并翻译。

**部署到 GitHub Pages（免费）**
1. 在 GitHub 新建一个仓库，名字随便（比如 `vocabflow`）；
2. 把本文件夹里的所有文件上传（网页端 "uploading an existing file" 直接拖进去）；
3. 仓库 Settings → Pages → Source 选 `main` 分支根目录，保存；
4. 等一分钟，访问 `https://<你的用户名>.github.io/vocabflow/` 即可。
